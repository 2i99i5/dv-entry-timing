# Методология и словарь данных

[English](METHODOLOGY.md)

## Дизайн

Ретроспективный описательный анализ `submitDate` и выдач в CEAC за DV-2017–2026. Пик поздних дат замечен до формализации анализа. Окно двух последних дат — выбранное после наблюдения описание, а не заранее зарегистрированная проверка гипотезы. Причинное влияние даты и оптимальный день не оцениваются.

## Очистка и исходы

Строка — кейс, потенциально включающий семью. ID уникален в файле. Для 2017 разделитель `;`, для остальных — `,`. Даты разных форматов распознаются; непустая ошибочная дата вызывает исключение. Пропуски сохраняются. Пустой статус и `None` исключаются из наблюдаемых кейсов и не считаются отказами. У защищённых записей отсутствие статуса не доказывает отсутствие кейса.

Кейс с выдачей: `Issued > 0`, то есть хотя бы одна зарегистрированная выдача. Это не доказывает выдачу основному заявителю, всем членам семьи или факт въезда. `principal_issued` отдельно считает статус `Issued`, как старый notebook; его трактовка как статуса основного заявителя отдельно не проверена. `visas` — сумма числового `Issued`.

`submitDate` лежит в ожидаемых периодах регистрации и используется как **приближение даты заявки**. Формальное определение поля не подтверждено; не установлено, что это дата DS-260. `statusDate` не используется как проверенная дата выдачи. Время до выдачи не оценивается.

## Выравнивание и показатели

Начало года — минимальная дата среди наблюдаемых кейсов всех регионов. Относительный день = календарная разность с началом + 1. Для EU то же начало. Периоды не растягиваются до общей длины.

- Количество: кейсы с `Issued > 0` за дату.
- Доля: эти кейсы / все наблюдаемые кейсы с известной датой за этот день.
- Концентрация двух дат: выдачи за максимальный день и предшествующий календарный день / выдачи за все даты года.

Последние даты определены по данным, официальные дедлайны отдельно не проверены. Время суток и часовые пояса недоступны. Регистрация может завершаться посреди последнего дня; разная длительность может объяснять пик на предпоследнем. Поправки на это нет.

Прежние графики 2024/2025 содержат интервалы Уилсона 95% при биномиальной модели. Они не учитывают смещение, пропуски, неопределённость снимка и состав регионов. Проверок значимости и доказательства отсутствия эффекта нет. На общих публикационных графиках полосы опущены для читаемости.

## Пропуски и ограничения

В 2024–2025 у всех NVC-кейсов нет даты. Покрытие — 44,05% и 43,30% наблюдаемых кейсов. Пропуски связаны со статусом: выборка с датой не представляет всех отобранных. Пропуски не восстанавливаются, Dark не считаются отказами.

DV-2026 — снимок 22 августа: 4 453 кейса с датой / 66 003 наблюдаемых (6,75%), 14 643 Dark. Он исключён из основного диапазона и столбчатого графика LinkedIn. Даты получения старых файлов 2017–2023 неизвестны, финальность не подтверждена. Пандемийные годы и регионы различаются по условиям обработки; наложение кривых этого не корректирует.

Нет проигравших участников, всех заявок по дням, полных дат отобранных, проверенных индивидуальных историй выдач и результатов adjustment of status. Не идентифицируются вероятность отбора, визы для любого участника и визы среди всех отобранных в зависимости от даты. Показатели условны на доступной выборке с датами. Кейсы отличаются от получателей виз: при подсчёте людей влияет размер семьи.

## Происхождение и воспроизводимость

Источник: [DV Charts](https://dvcharts.xarthisius.xyz/), сбор из [CEAC](https://ceac.state.gov/CEACStatTracker/Status.aspx), [архив](https://github.com/dvcharts/dvcharts.github.io). Исходные условия источника продолжают действовать; данные не перелицензируются.

`input/download_manifest.json` хранит URL, даты наблюдений, загрузки, размеры и SHA-256 для 2024–2026: 01.10.2024, 01.10.2025, 22.08.2026. Last-Modified сервера не является датой наблюдения.

`input_inventory.json` содержит хеши, разделители и происхождение всех входов. Для 2017–2023 точные даты получения и архивные соответствия неизвестны. Хеш идентифицирует файл, но не обеспечивает доступность. Новая загрузка может отличаться. Построчные CSV не публикуются.

Два уровня воспроизводимости:

1. **От агрегатов:** английские графики и таблица строятся `prepare_publication.py` без сети и исходников.
2. **От исходников:** `analyze_ceac.py` строит агрегаты заново. Для точного совпадения нужны одинаковые хеши. Загрузки 2024–2026 документированы, старые файлы нужно получить отдельно.

## Проверки

Независимый `csv.DictReader` сверяет с pandas уникальность ID, количество кейсов с датой, с выдачей, статусов Issued, сумму виз и итоги относительных дат. Все десять файлов прошли; результат — `validation_all_years.csv`. Тесты проверяют смешанные семейные исходы, пропуски, разделители и ошибочные даты. Графики проверяются визуально. Это проверяет вычисления, а не правильность сбора у источника.

## Словарь выходов

| Файл / поле | Значение |
|---|---|
| `coverage.csv` | Строки, наблюдаемые и датированные кейсы, покрытие, выдачи, Dark, границы дат |
| `date_coverage_by_status.csv` | Покрытие дат по статусам и годам |
| `daily_all.csv` | Дневные агрегаты по годам |
| `daily_by_region.csv` | То же по регионам |
| `relative_daily_all.csv` | Агрегаты по относительному дню |
| `last_two_days.csv` | Концентрация двух дат, количества, день пика, признак неполноты 2026 |
| `cases` | Наблюдаемые кейсы с датой |
| `issued_cases` | Кейсы с Issued > 0 |
| `principal_issued` | Строки со статусом Issued |
| `visas` | Сумма числового Issued |
| `share` | issued_cases / cases |
| `wilson_low`, `wilson_high` | Номинальные границы Уилсона 95% |
| `environment.json` | Версии программ при проверке |

Поддерживается «поздние даты дают существенную меньшую часть наблюдаемых кейсов с выдачей». Не поддерживаются «большинство получателей подались поздно», «поздняя подача повышает шансы», «дата не влияет». Больший числитель не доказывает большую вероятность без нужного знаменателя.
